# Audit Anti Slop Frontend RO

- **Mode:** AFTER (audit only)
- **Tanggal:** 2026-11-03
- **Basis pemeriksaan:** inspeksi source code pada branch `main`, terutama `templates/base.html`, template dashboard/masterdata/RO/admin, `static/css/themes.css`, `static/css/sb-admin-overrides.css`, dan `static/js/theme-switcher.js`.
- **Batas audit:** aplikasi tidak dijalankan dari lingkungan audit ini. Karena itu, temuan runtime, kontras aktual, keyboard flow, responsivitas visual, dan keberhasilan interaksi belum dapat dinyatakan teruji. Tidak ada file UI yang diubah.

## Temuan

### 1. [HIGH] Akses sentuh pada kontrol tema dan tombol kecil belum memenuhi target minimum
- **Aturan:** R-03 (Mobile Responsiveness).
- **Bukti source:** `static/css/sb-admin-overrides.css` mengatur `.theme-btn` menjadi 21px, lalu 17px pada viewport di bawah 576px. `themes.css` juga mengatur 28px, tetapi override yang dimuat setelahnya membuat ukuran efektif lebih kecil. Tombol Bootstrap diberi `min-height: 38px`, dan beberapa aksi tabel memakai `btn-sm`.
- **Dampak:** kontrol tema dan aksi kecil berpotensi sulit disentuh dengan jari, khususnya pada ponsel.
- **Arah perbaikan:** pertahankan tampilan visual yang ringkas bila diperlukan, tetapi sediakan area interaksi minimal 44×44px dan jarak yang cukup. Periksa juga kontrol lain yang memakai `btn-sm`.

### 2. [HIGH] Arah visual produk belum terdokumentasi
- **Aturan:** R-37 (Design Direction Required), R-20 (Visual Identity), R-31 (Every Decision Must Have a Reason).
- **Bukti source:** repository tidak memiliki `DESIGN.md` maupun `AGENTS.md` pada root saat diperiksa. CSS menetapkan lima tema, font global `Segoe UI, system-ui`, aksen, radius, dan shadow, tetapi alasan identitas/komposisinya tidak ditemukan pada file yang diperiksa.
- **Dampak:** pilihan visual belum dapat dibedakan dari konfigurasi template admin generik dan tidak memiliki acuan yang konsisten untuk pengembangan berikutnya.
- **Arah perbaikan:** pemilik produk menetapkan arah visual RO (karakter, warna, tipografi, kepadatan informasi, dan perilaku tema). Jangan mengarang identitas visual atas nama pemilik.

### 3. [HIGH] Lima tema belum memiliki bukti verifikasi menyeluruh
- **Aturan:** R-34 (Every Theme You Ship Must Work).
- **Bukti source:** UI menyediakan Light, Dark, Ocean, Forest, dan Sunset. `sb-admin-overrides.css` memberi penyesuaian khusus yang cukup luas untuk Dark, sedangkan Ocean/Forest/Sunset hanya memiliki beberapa override permukaan. Tidak ada bukti pengujian seluruh komponen pada kelima tema.
- **Dampak:** konsistensi tabel, form, modal, dropdown, sidebar, pesan, dan state fokus antar tema belum terjamin.
- **Arah perbaikan:** uji setiap halaman dan komponen pada kelima tema. Perbaiki tema yang tidak konsisten atau kurangi pilihan tema yang belum siap setelah keputusan pemilik produk.

### 4. [MEDIUM] Dashboard mengikuti pola shell admin generik
- **Aturan:** R-05 (Layout & Page Structure), R-14 (Feature Cards), R-31.
- **Bukti source:** `templates/masterdata/dashboard.html` menggunakan topbar/sidebar global, empat kartu statistik berukuran setara, lalu satu kartu informasi umum. Pola ini sama dengan pola dashboard shell yang diperingatkan Anti Slop. Kartu memiliki aksen warna dan ikon seragam.
- **Dampak:** dashboard belum menunjukkan prioritas kerja RO yang khas, misalnya tindakan utama atau status operasional yang benar-benar membantu peran pengguna.
- **Arah perbaikan:** susun ulang berdasarkan pekerjaan nyata tiap role dan data yang memang tersedia. Jangan menambah grafik, angka, atau status yang belum bersumber dari data aplikasi.

### 5. [MEDIUM] Shadow dan ikon digunakan sebagai gaya default lintas halaman
- **Aturan:** R-12 (Shadow), R-04 (Icons), R-31.
- **Bukti source:** `themes.css` menerapkan shadow pada seluruh `.card`; template admin juga menambahkan `shadow-sm`. Ikon Font Awesome muncul hampir di seluruh judul, tombol, navigasi, dan kartu. Tidak ditemukan catatan alasan elevasi atau alasan pemilihan set ikon.
- **Dampak:** hirarki permukaan dan ikon menjadi seragam; ikon berisiko menjadi ornamen, bukan penanda informasi.
- **Arah perbaikan:** gunakan elevasi hanya pada elemen yang perlu menonjol. Pertahankan ikon yang membantu mengenali aksi/entitas dan hilangkan yang hanya mengulang label.

### 6. [HIGH] Belum ada bukti build, click-through, dan pemeriksaan aksesibilitas lintas breakpoint
- **Aturan:** R-25 (Color Contrast), R-32 (Keyboard Accessibility), R-35 (Verify Before You Deliver).
- **Bukti source:** source menunjukkan label form yang terlihat pada beberapa halaman dan Bootstrap menyediakan perilaku fokus dasar, tetapi audit ini tidak menjalankan aplikasi, mengukur rasio kontras, menelusuri urutan keyboard, memeriksa Escape pada modal, atau mengklik semua kontrol pada tema dan ukuran layar berbeda.
- **Dampak:** kepatuhan aksesibilitas dan keberfungsian antarmuka belum dapat dinyatakan lulus hanya dari inspeksi template.
- **Arah perbaikan:** setelah temuan yang disetujui diperbaiki, jalankan aplikasi dan lakukan click-through per halaman, per tema, serta desktop/tablet/mobile. Catat hasil setiap kontrol dan error console.

## Catatan yang tidak dijadikan temuan
- Navigasi sidebar yang diperiksa mengarah ke named Django URL yang tersedia pada template; keberadaan runtime route belum diuji.
- Beberapa halaman sudah memiliki empty state dan label form eksplisit.
- Tidak ada dasar cukup dari source yang diperiksa untuk menyimpulkan bahwa seluruh halaman mengalami horizontal overflow atau bahwa semua kontrol tidak dapat digunakan dengan keyboard.

## Status
Audit source-code selesai. **Belum ada perbaikan UI yang dilakukan.** Temuan menunggu persetujuan pemilik produk. Setelah persetujuan, hanya nomor yang disebutkan yang akan ditangani.


## Tindak lanjut persetujuan pemilik produk

Pemilik produk menyetujui temuan **2, 3, 4, dan 5**. Source-code tindak lanjut telah dikomit ke branch `main`:
- Temuan 2: menambahkan root `DESIGN.md` sebagai arah visual produk.
- Temuan 3: menyatukan token semantik dan styling komponen untuk lima tema pada `static/css/themes.css`, serta menyelaraskan shell pada `static/css/sb-admin-overrides.css`.
- Temuan 4: mengubah dashboard agar menonjolkan Daftar RO, tombol Buat RO khusus Administrator, dan jumlah master yang tersedia.
- Temuan 5: menghilangkan shadow default kartu dan mengurangi ornamen dashboard; ikon dashboard dekoratif dihapus.

**Status:** perubahan source telah dilakukan, tetapi belum diverifikasi melalui browser/server. Kelima tema, kontras aktual, dan layout pada desktop/tablet/mobile masih memerlukan pengujian. Temuan 1 dan 6 tetap belum ditangani sesuai batas persetujuan.
